Payment Safety

Gate A runs before draft creation — if payment evidence exists, no draft is created.
Gate B runs immediately before send — if payment evidence appears after approval, the send is cancelled.
Idempotency — each send operation has a unique key preventing duplicate emails.
Hard-stop states — PAYMENT_CLAIMED, PAID_CONFIRMED, DISPUTED, and SEND_BLOCKED prevent any reminder sends.
